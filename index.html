Why three links used to be the minimum? Importing is “download → detect format → import”, and one file can only hold one format (legado book source array / MoonTV collector config / Venera source index). The three structures are mutually incompatible. Novel and comic legado packs can be merged, and the two video packs share a format, but Venera runs its own JS sources and cannot coexist with the others. Since v1.5.6.0 the app understands the leimaoPack manifest (all.json), which handles multi-file download and merging, so one link is enough.
